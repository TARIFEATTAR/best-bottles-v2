## 🎯 TIPS FOR BEST RESULTS

### For Google ImageFX / Gemini:

1. **Run each prompt separately** - Generate one component at a time
2. **Regenerate 3-4 times** - Pick the best result from multiple generations
3. **Check transparency** - Make sure background is truly transparent
4. **Verify proportions** - Components should look like they'd fit together
5. **Consistent lighting** - All pieces should have same light direction

### Post-Processing in Photoshop:

1. **Remove any background artifacts** - Clean up edges
2. **Match color temperature** - Ensure consistent white balance
3. **Resize to 1024x1024** - Standard canvas size
4. **Position correctly** - Follow the zone guide in IMAGE_CREATION_GUIDE.md
5. **Save as PNG-24** - Preserve transparency

### Quality Checklist:

- [ ] Background is 100% transparent
- [ ] No shadows baked into the image  
- [ ] Lighting direction consistent (upper-left)
- [ ] Glass reflections look realistic
- [ ] Proportions match real product specs
- [ ] Clean, sharp edges (no jagged pixels)
- [ ] Saved as PNG with alpha channel
